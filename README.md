# ChantierMarket — site de démonstration

Site vitrine et plateforme de simulation de ChantierMarket, la marketplace des matériaux de chantier autour de Lorient (projet étudiant).

- Tout est simulé : aucun paiement réel, aucune donnée envoyée. Les données de la simulation restent dans le navigateur de chaque visiteur.
- Les coordonnées, numéros de société et comptes de démonstration sont fictifs.

Ce dépôt public contient uniquement le site. Il est publié automatiquement avec GitHub Pages.
